# Divya Srinivasan — Portfolio

ReframeHK-inspired draggable tile portfolio built with React and Vite. This is an original implementation, not a copy of the reference site.

## Run locally

1. Install Node.js LTS from https://nodejs.org
2. Open this folder in VS Code.
3. Open Terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL displayed in the terminal (typically http://localhost:5173).

## Deploy

Push this folder to GitHub, then import the repository into Vercel. Vercel should detect Vite. Build command: `npm run build`; output directory: `dist`.
